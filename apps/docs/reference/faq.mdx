description: 'Frequently asked questions.'
---

**Is the runtime deterministic?** Yes. AI is only used during ingestion.

**What inputs are supported?** OpenAPI, Swagger, GraphQL, HAR, Postman, and
observed traffic.

**Does Carbon send my traffic anywhere?** No. The runtime is local. Cloud
sync is opt-in per project.

**Can I self-host?** The runtime is local by default. Enterprise adds a
self-hosted control plane.
