---
title: 'Using Carbon in CI'
description: 'Deterministic replicas in your continuous integration.'
---

Carbon runs as a plain Node process in CI.

```yaml
- run: npm install -g carbon-api
- run: carbon emulate --from ./stripe.json --port 8787 &
- run: pnpm test
  env:
    STRIPE_API_BASE: http://localhost:8787
```

Use the same snapshot and runtime in development and CI to reduce drift between
environments.
