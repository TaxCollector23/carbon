The State Engine powers every Carbon replica.

## Guarantees

- **Consistency.** After a successful write, subsequent reads reflect it.
- **Isolation.** Transactions roll back cleanly on failure.
- **Portability.** Snapshots serialize the full state to a stable JSON blob.

## Snapshots

```ts
const snap = await replica.snapshot.save('after-refund');
// …later, or in another test file
await replica.snapshot.restore(snap);
```

Snapshots travel with your code. Reviewers can replay them, and CI can restore
them.
