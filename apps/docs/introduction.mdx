Carbon is an API behavior engine. Point it at an OpenAPI spec, a Postman
collection, a HAR file, or a live URL. It analyzes the shape and behavior of
the API, compiles that into an intermediate representation and a behavior
graph, and then boots a fast, deterministic local runtime you can develop
against.

Existing mocking tools return static JSON. Carbon models state.

## Why Carbon

- **Behavioral, not static.** A POST changes what future GETs return.
- **Deterministic.** The runtime is pure — same input, same output, every time.
- **Local by default.** No egress. No third-party data path.
- **Composable.** Snapshots, branches, and replays ship with your code.
