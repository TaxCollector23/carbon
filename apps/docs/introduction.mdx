Carbon is an API behavior engine. Give it an OpenAPI spec, AsyncAPI document,
Protobuf or gRPC service definition, Postman collection, HAR file, GraphQL
schema, or recorded traffic. Carbon analyzes the API shape, builds an
intermediate representation and behavior graph, then runs a deterministic
replica you can use in development, CI, or shared review environments.

Static mocks return canned JSON. Carbon keeps state, so writes affect later
reads.

## Why Carbon

- **Stateful behavior.** A `POST` changes what future `GET`s return.
- **Deterministic.** The same inputs produce the same outputs.
- **Controlled traffic path.** Runtime traffic stays in the replica unless you configure another path.
- **Portable state.** Snapshots, branches, and replays travel with your code.
