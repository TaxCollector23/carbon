---
title: 'CLI overview'
description: 'Carbon command-line workflows.'
---

Use the Carbon CLI to record traffic, ingest API definitions, run replicas, and
inspect behavior graphs.

```bash
carbon init             # scaffold a project
carbon login            # show API-key auth guidance
carbon record <url>     # observe traffic
carbon ingest <spec>    # parse a spec / schema / HAR / collection
carbon emulate          # run a deterministic replica
carbon inspect          # explore the behavior graph
carbon snapshot save    # freeze state
carbon replay <rec>     # deterministically replay
```
