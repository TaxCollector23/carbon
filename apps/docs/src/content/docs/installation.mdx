title: 'Install'
description: 'Install the Carbon CLI on macOS, Linux, or Windows.'
---

## npm (recommended)

```bash
npm install -g carbon-api
```

The package name is **`carbon-api`**; the primary binary is `carbon`
(`carbon-api` and `carbon-dev` are linked as aliases). Requires Node.js
22.13 or newer.

## One-liner script

```bash
curl -fsSL https://raw.githubusercontent.com/TaxCollector23/carbon/master/install.sh | sh
```

Fetches the latest published tarball and installs it into your global npm
prefix.

## Ephemeral

```bash
npx carbon-api <command>
```

## Verify

```bash
carbon --version
carbon doctor
```

`carbon doctor` runs a local diagnostic — Node version, pnpm, port
availability on 1223/3001/4000, saved credentials, API URL,
`DATABASE_URL`/`REDIS_URL` sanity, and docker presence — so you can tell
right away whether the environment is ready.

## Shell completion

```bash
carbon completion bash >> ~/.bashrc
carbon completion zsh  >  ~/.zsh/completions/_carbon
carbon completion fish >  ~/.config/fish/completions/carbon.fish
```
