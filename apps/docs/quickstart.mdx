## Install

```bash
curl -fsSL https://raw.githubusercontent.com/TaxCollector23/carbon/master/install.sh | sh
```

Or with your favorite package manager:

```bash
npm install -g carbon-api
```

## Initialize a project

```bash
mkdir acme && cd acme
carbon init
```

This scaffolds a `carbon.config.ts` and a `.carbon/` directory.

## Ingest an API

```bash
carbon ingest https://api.stripe.com/openapi.json
```

## Emulate

```bash
carbon emulate --from ./stripe.json --port 8787
```

Swap your base URL to `http://localhost:8787` and use the same runtime locally
and in CI.
