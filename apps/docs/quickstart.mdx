---
title: 'Quickstart'
description: 'Start your first replica from a spec or recording.'
---

## Install the CLI

```bash
curl -fsSL https://raw.githubusercontent.com/carbon-dev/carbon/master/install.sh | sh
```

Or install with npm:

```bash
npm install -g carbon-api
```

## Create a project

```bash
mkdir acme && cd acme
carbon init
```

This creates `carbon.config.ts` and a `.carbon/` directory for snapshots and
cache files.

## Ingest an API

```bash
carbon ingest https://api.stripe.com/openapi.json
```

## Run the replica

```bash
carbon emulate --from ./stripe.json --port 8787
```

Point your app at `http://localhost:8787` and use the same runtime in
development, CI, or review environments.
