---
title: 'Installation'
description: 'Install the Carbon CLI.'
---

## macOS / Linux

```bash
curl -fsSL https://raw.githubusercontent.com/carbon-dev/carbon/master/install.sh | sh
```

## Node

```bash
npm install -g carbon-api
```

Requires Node.js 20 or later.

## Verify

```bash
carbon --version
```
